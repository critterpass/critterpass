## 1. Conventions

| Item | Rule |
|---|---|
| Base URLs | `https://api.critterpass.app` (api), `wss://rt.critterpass.app` (Centrifugo), `https://sync.critterpass.app` (PowerSync), `https://media.critterpass.app` (media Worker), `https://critterpass.app` + `https://go.critterpass.app` (web/links) |
| Versioning | Path prefix `/v1`; zod schemas in `packages/domain`; `/openapi.json` generated by `@hono/zod-openapi`; app uses typed `hc` client; Swift/Kotlin extension clients generated from `/openapi.json` (subset tagged `ext`) |
| IDs | UUIDv7 everywhere (domain rows, `op_id`, event ids, Better Auth ids via `generateId`) |
| Time | ISO-8601 with offset on the wire; store `timestamptz` + IANA `tz` where local time matters (leave-by, resets, roundup) |
| Money | `{amount_minor: int, currency: ISO-4217}`; FX via Frankfurter snapshot id `fx_snapshot_id`; all arithmetic in `packages/cost-engine` |
| Errors | `{error: {code, message, retryable, detail?}}` (codes §3) |
| Auth header | `Authorization: Bearer <better-auth session token>` (app, via `@better-auth/expo`); short JWT (EdDSA, 10–15 min, `aud` = `sync` or `rt`) only for PowerSync/Centrifugo |
| Rate limits | Better Auth secondary storage (Redis) for auth routes; Hono middleware token bucket per uid + per IP for others; 429 `RATE_LIMITED` with `retry_after_s` |
| Locale | `Accept-Language` + `X-CP-TZ`; AI output language = app locale |
| Tracing | W3C `traceparent` accepted; `X-Request-Id` echoed; Sentry + OTel |
| Pagination | cursor `?cursor=&limit=` → `{items, next_cursor}` |

## 2. Command envelope, idempotency, results

### 2.1 Envelope (`packages/domain/src/commands/envelope.ts`)

```ts
type CommandEnvelope<P> = {
  op_id: string;            // client UUIDv7, idempotency key
  cmd: CommandName;         // verb_noun, e.g. "cast_ballot"
  v: 1;                     // schema version of cmd
  actor: {
    uid: string;            // must equal authenticated uid (server overwrites + asserts)
    via: 'app' | 'offline' | 'widget' | 'notif_action' | 'la_intent' | 'app_intent' | 'system' | 'admin';
  };
  device: { id: string; platform: 'ios' | 'android' | 'web'; app_version: string; tz: string };
  client_ts: string;        // device clock; server stores skew, never trusts for ordering
  base_version?: number;    // optimistic concurrency where the aggregate is versioned
  payload: P;               // zod-validated per cmd
};
```

### 2.2 Transports (one handler registry)

| Transport | Used by | Auth | Response |
|---|---|---|---|
| PowerSync upload → `POST /sync/upload` (batch, ordered) | commands marked **O** (offline-capable) | session bearer | Always 2xx for validation/business rejects; outcome written to `cmd_results`; 5xx only for transient errors (client retries batch) |
| `POST /v1/cmd/{cmd}` | online-only commands (payments intents, invites accept, supplier book) and O commands when online and a synchronous result is needed | session bearer | 200 `{status, result}` or error envelope; also writes `cmd_results` |
| `POST /v1/actions` | iOS extensions, Android receivers (widget / notification action / LA intent / App Intent) | device action key (async doc §5) | 200 `{status, result, snapshot?}`; scope-limited command subset |
| worker/system | jobs | `app_system` role | n/a |

Handlers: `services/api/src/commands/<domain>/<verb_noun>.ts` exporting `{schema, authorize, entitle, handle}`; shared by api and worker.

### 2.3 Execution pipeline (every command)

1. Parse envelope + payload (zod). Overwrite `actor.uid` with session uid (or action-key uid).
2. `BEGIN`; `SET LOCAL ROLE app_user`; `set_config('app.uid', uid, true)`.
3. `INSERT INTO cmd_log(op_id, uid, cmd, payload_hash) ON CONFLICT DO NOTHING`. If exists: same hash → return stored result with `status: duplicate`; different hash → `IDEMPOTENCY_MISMATCH`.
4. `authorize()` app-layer policy (membership, role, state machine). RLS backstop catches scope bugs.
5. `entitle()` via `packages/entitlements` (quota reservations in same tx; released on failure).
6. `handle()` writes aggregates; appends `domain_events`, `rt_outbox` rows, pg-boss jobs (same tx).
7. Write `cmd_results`; `COMMIT`.
8. Worker relays `rt_outbox` → Centrifugo; PowerSync streams changed rows.

### 2.4 Tables

| Table | Columns | Sync | Retention |
|---|---|---|---|
| `cmd_log` | `op_id pk, uid, cmd, payload_hash, result jsonb, created_at` | no | 30 d (maint job) |
| `cmd_results` | `op_id pk, uid, cmd, status (applied\|rejected\|duplicate), code?, detail jsonb?, result_ref jsonb (created ids, new version), server_ts` | yes (own-user bucket) | 14 d |
| `domain_events` | `id uuidv7, type, aggregate, aggregate_id, crew_id?, trip_id?, actor_uid, data jsonb, at` | no | 400 d (analytics export, recap) |
| `rt_outbox` | `id, channel, payload jsonb, created_at, sent_at?` | no | 7 d after send |

Client contract: optimistic write to local SQLite; on `cmd_results.status = rejected` roll back the optimistic row, show the code's copy (i18n key `errors.<code>`).

## 4. Command catalogue

Legend. **Surfaces:** A app online · O offline outbox (PowerSync) · W widget intent · N notification action · L Live Activity intent / AlarmKit intent · I App Intent (Siri/Shortcuts/Controls) · S system/worker · X admin/ops console.
**Authz:** self · member(crew) · participant(trip) · organiser(trip, any organiser) · voter(poll) · recipient(proposal) · payer/payee · owner(row) · ops(admin role).
**Ent:** entitlement/quota check (rules in `packages/entitlements`, matrix = master §8). "–" = always free.
Every command also emits the generic `cmd.applied` metric; listed events are domain events (`aggregate.past_tense`). Phase = where the handler is built.

Categories: `prompt_injection`, `harassment`, `sexual`, `self_harm`, `violence`, `illegal`, `personal_info`, `promotion`.

| Surface | Categories | Outcome | Both providers down |
|---|---|---|---|
| `guide_input` (guide chat, mentions, voice) | injection, self-harm, violence, harassment | never `reject`: injection → the turn's write tools are removed (or refused once the verdict lands); self-harm or violence → `help_card{topic: safety}`; the check starts before the context build and the turn waits for it at most 25 ms | `pass`, the turn still wraps untrusted text |
