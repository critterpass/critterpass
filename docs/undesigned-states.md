# Undesigned states

States and assets built from existing components/tokens because no design render or product
decision covers them yet. Logged here per `CLAUDE.md` for founder review — not silently shipped as
if they were verified design values.

Badges read "{tab}, {n} new".                                                                                                                                                                                                                                                                                                                                                                                          |
| Sheet (`apps/mobile/src/ui/sheet/Sheet.tsx`)                                        | Scrim tap; reduced motion                                            | A tap on the .45 scrim dismisses like ✕ (iOS sheet convention; the design names ✕, drag and Android back only). Under reduced or off motion the sheet and rise cross-fade in 200 ms and the presenter stays at full size (no .93 scale), per §5's "spatial transitions → 200 ms cross-fade".                                                                                                                                                                                                                                                                                                                                                                                                 |
| Push edge-swipe (`apps/mobile/src/lib/navigation/transitions.ts`)                   | iOS back swipe commit point                                          | The JS stack commits when `dx + v × impact > width / 2`; impact is set so a .55 pt/ms flick commits on a 390 pt screen, but a slow drag commits at half the width rather than the designed 110 pt. Android uses the system predictive back gesture (targetSdk 36) with the stack's pop animation, not a custom predictive preview.                                                                                                                                                                                                                                                                                                                                                           |
| Zoom (`apps/mobile/src/ui/transitions/SharedGrow.tsx`) | Destination never measures; source gone on back | The clone waits over the card for one `base` beat (340 ms) for the detail to report its frame, then grows to the full window. Going back when the card has scrolled away or unmounted skips the unzoom and the route's own 260 ms unfade plays, as the spec's fallback says. |
